# ShopSense AI

**AI-Powered Online Shopper Purchase Intention Prediction & Analytics Platform**

ShopSense AI combines the academic machine-learning experiment already in this repository with a complete web application architecture:

- **React + Vite** frontend
- **Node.js + Express** REST backend
- **MongoDB + Mongoose** application database
- **FastAPI** ML inference service
- **scikit-learn** trained purchase-intention model
- Existing UCI dataset, preprocessing, EDA, evaluation, notebook, reports and model artifact

## Architecture

```
React / Vite :5173
      |
      v
Express API :5000  -----> MongoDB :27017
      |
      v
FastAPI ML Service :8000
      |
      v
models/best_model.joblib
      |
      v
UCI Online Shoppers Purchasing Intention dataset
```

MongoDB is used for **application persistence**: users and prediction history. The UCI CSV remains the reproducible ML training/evaluation source.

## Main application flow

1. User registers or signs in.
2. React sends authenticated requests to the Express API.
3. A prediction request is validated and forwarded to the FastAPI inference service.
4. FastAPI loads the saved scikit-learn pipeline and returns the predicted class, probabilities, confidence and intent level.
5. Express stores the input and result in MongoDB.
6. React displays the prediction and the user can review historical predictions.
7. The Model page reads the actual evaluation metrics generated by the ML experiment.

## Local setup

### 1. MongoDB

Install and run MongoDB Community locally, or use a MongoDB deployment and put its connection string in `backend/.env`.

Default local database:

```
mongodb://127.0.0.1:27017/shopsense_ai
```

### 2. ML service

From the repository root:

```bash
python -m venv .venv
# activate the environment
pip install -r ml-service/requirements.txt
uvicorn main:app --app-dir ml-service --reload --port 8000
```

Health endpoint:

```
http://localhost:8000/health
```

### 3. Express backend

```bash
cd backend
npm install
```

Copy `backend/.env.example` to `backend/.env` and set:

```
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/shopsense_ai
JWT_SECRET=use-a-long-random-secret
ML_SERVICE_URL=http://127.0.0.1:8000
CLIENT_URL=http://localhost:5173
```

Then:

```bash
npm run dev
```

Health endpoint:

```
http://localhost:5000/api/health
```

### 4. React frontend

In another terminal:

```bash
cd frontend
npm install
```

Copy `frontend/.env.example` to `frontend/.env` if needed, then:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

## ML experiment

The original academic pipeline remains intact.

Run:

```bash
pip install -r requirements.txt
python run_project.py
```

The project includes preprocessing, feature engineering, EDA, multiple classifiers, class-imbalance analysis, hyperparameter tuning, evaluation, model interpretation and an executed notebook.

The current evaluation artifacts are stored under `reports/`, including `model_comparison.csv`.

## Database collections

MongoDB currently stores:

- `users` — account identity and bcrypt password hashes
- `predictions` — authenticated prediction inputs, outputs, probabilities, intent levels and timestamps

The raw ML dataset is deliberately not moved into MongoDB; keeping it as a versioned training source makes the academic experiment reproducible.

## Security basics implemented

- Passwords are hashed with bcrypt.
- JWT authentication protects prediction/history/analytics endpoints.
- Password hashes are excluded from normal user queries.
- Secrets are supplied through environment variables.
- `.env` files and dependency directories are ignored by Git.
- Prediction history is scoped to the authenticated user.
